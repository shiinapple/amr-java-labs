## API 网关六个模块怎么讲

**具体问题。** 新的订单查询服务上线后，谁负责把它的信息交给网关？流量进来时，哪一部分决定处理方法？节点下线后，谁负责刷新映射？

**通俗解释。** 可以先画两条线。流量线负责处理一条进来的请求。配置线负责为流量线准备规则和节点信息。每条线各有入口，路由表是两条线接触的位置。

**正式概念。** 处理请求的部分常称为数据面，负责下发配置、维护服务信息的部分常称为控制面。下面按简历列出的模块名称给出一组用于面试复述的职责和交互。分层是教学还原，实际调用方向和部署结构应以项目实现为准。

| 简历模块 | 可以怎样解释 | 可以追问什么 |
| --- | --- | --- |
| 核心通信 | 接收请求，解析参数，组织会话和调用流程，适配下游数据源 | 业务异常和传输异常在哪里映射成响应？ |
| 服务助手 | 提供业务服务接入所需的配置或注册辅助能力 | 服务方需要改哪些代码？接口元数据是哪来的？ |
| 启动引擎 | 装配配置、核心组件和运行环境，启动网关实例 | 拉取配置失败时能不能接受流量？ |
| 注册中心 | 保存网关实例或服务的可用信息，提供注册与发现 | 服务注册事件发生乱序怎么办？ |
| 上报服务 | 接收实例或服务上报并维护相关状态 | 心跳丢失、主动下线和发布配置分别怎么处理？ |
| 管理后台 | 维护可见服务、路由与节点配置 | 怎样灰度、审计与回滚？ |

**完整示范。** 订单服务的接入配置描述公开路由和 RPC 方法签名。网关启动并拿到版本 3 的全量路由配置。随后请求进入核心通信，选中公开映射，按签名转换 `C001` 与 `2`，下游返回结果。与此同时订阅端收到较早的 v2，应保持 v3。用 [14](../14-http-rpc-lab/README.md) 的调用记录和 [15](../15-route-snapshot-lab/README.md) 的版本测试分别演示两条线。Nginx 负载均衡决定入口请求流向哪个网关节点，[16](../16-rate-limit-lab/README.md) 练的是单节点如何给请求配额。解释简历中的 Spring Boot Starter 时，优先说你能指认的装配入口和配置项。鉴权、去重、重试等能力也以可指认的实现为依据。

**独立练习。** 画出“原节点下线，新版本先发布，一条旧请求还未结束”的三条时间线。标出管理侧提交、网关接收配置、入口切换、旧连接收尾的次序。再解释：路由更新成功、节点健康检查通过、旧请求结束，分别由什么观测来证明。

## 用一分钟讲一个项目点

- **前 15 秒交代场景。** AMR Gateway 把固定作业路线转成控制器能接收的路段；或 API 网关把外部 HTTP 请求转成服务调用。
- **中间 30 秒用一个输入讲方法。** 例如 `pump` 等应答时再次被调度。先标记发送中，再预占下发边界，收到明确失败时回退。已发送与已完成分开推进。
- **最后 15 秒说验证和个人分工。** 讲你实际参与的代码点或现场工作。能指认模拟用例时说清模拟了哪类消息。能指认实机记录时说明观察到了什么。量化结果写明数据集、基线、验证时间。

练习口述可以用这段作为开头，再换成你自己的分工与证据：

> 固定路线分批下发后，控制器应答有等待时间，调度在这期间还可能被触发。发送前我会先看是否已有一批在途，并区分发送下标与完成下标。练习里我让第一次发送的 Future 保持未完成，再触发一次调度，检查控制器只收到一次。现场若发生超时，还需要用任务标识和实际反馈核对是否已执行。

## 自测题

1. 面试官问“为什么不用反射直接调用用户传来的方法名”，你准备用哪一道练习里的哪个对象回答？
2. 注册中心订阅断开，网关恢复连接后发现跳了三个版本。全量和增量事件各怎样处理？
3. 说“实习里优化了网关”太宽泛。若你只有代码与本地对照用例，怎样把表述说具体？
4. 面试官问“已经是微服务了，为什么还需要限流？”用令牌桶例子解释，再补一句它保护不了什么。

## 答案与解析

1. 用 14 的 `RouteKey → Route → Invocation`。公开入口与授权映射限定调用目标，客户端参数只参与绑定。要加权限，应在实际执行前再次按路由校验。
2. 判断线索是拿到的版本包含多少状态。全量可以直接发布正确的最新表。增量需要确认连续性，缺事件时补拉或回放，随后再开放依赖这份配置的路径。
3. 描述一个自己做过的变化，例如按地图内容与车型缓存展示预检结果，然后给出可重复的测法和对照结果。团队设计和个人工作按实际参与分别讲，测试环境与指标口径一并交代。
4. 网关需要约束入口能在短时间内压进多少请求。容量允许适量突发，补充速率控制长期速率。若下游长期慢，已放行请求仍可能积压，需要另外限制在途量。
